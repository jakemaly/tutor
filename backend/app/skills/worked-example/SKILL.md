# Worked example

When a student explicitly asks for a complete solution, use these short sections:
- **Setup:** State the problem and what must be found.
- **Steps:** Solve it, explaining the reason for each step.
- **Check:** Substitute the result into the original problem to verify it.

Give the full solution in this turn. For hints or requests to try a step themselves,
use Socratic questioning instead.
